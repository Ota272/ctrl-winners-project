## ✨ О проекте

**CapFinance Game** — веб-приложение, в котором можно попробовать разные способы управления виртуальным капиталом: покупать и продавать активы, обменивать валюты, распределять деньги между портфелем и депозитом, следить за историей операций и сравнивать результаты с другими игроками.

После регистрации игрок получает **100 000 виртуальных USD**. Дальше — выбор стратегии, первые сделки и знакомство с финансовыми инструментами на практике.

Встроенный **«Капитал Бот»** на базе Google Gemini отвечает на вопросы с учётом контекста портфеля. Интерфейс преимущественно на русском языке и ориентирован на мобильный формат: основные разделы переключаются внутри одного игрового экрана.

> 🎓 Деньги и сделки в приложении виртуальные. Часть котировок поступает из внешних сервисов, а часть цен и игровых механик моделируется внутри приложения.

## 🚀 Быстрый старт

Для запуска нужны **Python 3.10+** и доступ в интернет для загрузки зависимостей, CDN и внешних API.

Скачайте или клонируйте репозиторий и откройте терминал в корне проекта.

### 1. Создайте окружение и установите зависимости

<details open>
<summary><strong>🪟 Windows · PowerShell</strong></summary>

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

</details>

<details>
<summary><strong>🐧 Linux / 🍎 macOS · Bash</strong></summary>

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

</details>

### 2. Настройте переменные окружения

Укажите `SECRET_KEY`. Для работы ИИ-чата также нужен `GEMINI_API_KEY`. Команды приведены в разделе [«Настройка окружения»](#environment).

### 3. Создайте базу и запустите приложение

**Windows · PowerShell:**

```powershell
.\.venv\Scripts\python.exe create_db.py
.\.venv\Scripts\python.exe app.py
```

**Linux / macOS · в активированном окружении:**

```bash
python create_db.py
python app.py
```

Откройте **[http://127.0.0.1:5000](http://127.0.0.1:5000)**. Без активной сессии приложение перенаправит на страницу входа. Зарегистрируйтесь, чтобы получить стартовый капитал и начать игру.

При изменении `PORT` используйте соответствующий порт в адресе браузера.

<a id="environment"></a>
## ⚙️ Настройка окружения

| Переменная | Назначение |
| --- | --- |
| `SECRET_KEY` | Секрет Flask для подписи сессий. Для развёртывания задайте собственное случайное значение |
| `GEMINI_API_KEY` | Серверный ключ Gemini для ИИ-чата. Без него ответы ассистента недоступны |
| `PORT` | Порт при запуске через `python app.py`; по умолчанию — `5000` |

Задайте переменные **в том же терминале**, из которого запускаете приложение.

**Windows · PowerShell:**

```powershell
$env:SECRET_KEY = (.\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_hex(32))")
$env:GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
$env:PORT = "5000"
```

**Linux / macOS · в активированном окружении:**

```bash
export SECRET_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
export GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
export PORT=5000
```

Замените `YOUR_GEMINI_API_KEY` своим ключом. Если ИИ-чат не нужен, переменную `GEMINI_API_KEY` можно не задавать.

Для локальных запусков команды выше создают новый секрет сессий. В развёрнутом приложении сохраните постоянный секрет в настройках окружения хостинга.

<a id="services"></a>
## 🌐 Внешние сервисы

| Сервис | Использование | Настройка |
| --- | --- | --- |
| **Finnhub** | Котировки акций | `STOCK_API_KEY` в `static/game.js` |
| **CoinGecko** | Криптовалюты, «металлы» и курс TON | Публичный endpoint `simple/price`, используемый клиентом |
| **Google Gemini** | Ответы «Капитал Бота» | `GEMINI_API_KEY` в окружении сервера |

Запросы к Finnhub и CoinGecko выполняются из браузера. Доступность котировок зависит от внешних сервисов и их ограничений на запросы.

Ключ Finnhub в клиентском JavaScript виден пользователям. Если требуется скрыть токен, запросы нужно перенести на сервер: подстановка ключа в браузерный конфиг сама по себе его не скрывает.

<a id="database"></a>
## 🗄️ База данных

`create_db.py` создаёт три таблицы:

| Таблица | Содержимое |
| --- | --- |
| `users` | ID, уникальное имя пользователя и пароль |
| `user_state` | `user_id`, `balance`, `deposit`, `usd`, `kzt`, `jpy` и активы в JSON |
| `history` | Тип операции, актив, количество, цена, сумма, снимок баланса и время |

Типы операций включают `BUY`, `SELL`, `EXCHANGE` и `GAME`.

Приложение выбирает путь к SQLite в зависимости от окружения:

- **Локально:** `database.db` в корне проекта.
- **При наличии каталога `/data`:** `/data/database.db` для постоянного хранения на сервере.

При развёртывании убедитесь, что таблицы созданы в том файле, который использует приложение. Базу с пользовательскими данными не следует добавлять в репозиторий.

<a id="api"></a>
## 🔌 HTTP API

Игровые JSON-маршруты используют сессионную авторизацию через cookie после входа. Регистрация и вход служат точками начала работы с аккаунтом.

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `POST` | `/api/register` | Создать аккаунт и выдать 100 000 виртуальных USD |
| `POST` | `/api/login` | Войти и установить сессию |
| `GET` | `/logout` | Очистить сессию и перейти на страницу входа |
| `GET` | `/api/get_state` | Получить портфель и поле `roulette_loss` для интерфейса |
| `POST` | `/api/save_game` | Сохранить балансы, депозит и активы |
| `GET` | `/api/history` | Получить до 50 последних операций пользователя |
| `POST` | `/api/log_action` | Записать операцию в историю |
| `GET` | `/api/leaderboard` | Получить топ-10 по `capital = usd + deposit` |
| `POST` | `/api/chat` | Передать сообщение и контекст портфеля; получить `reply` |

<details>
<summary><strong>📦 Основные поля JSON-запросов</strong></summary>

| Маршрут | Поля |
| --- | --- |
| `/api/register`, `/api/login` | `username`, `password` |
| `/api/save_game` | `usd`, `kzt`, `jpy`, `deposit`, `assets` |
| `/api/chat` | `message`, `context` — например, текущие `usd` и `assets` |

</details>

**Страницы приложения:** `/`, `/login`, `/register`, `/shop.html`, `/rules.html`, `/offer.html`, `/policy.html`, `/report.html`.

<a id="deployment"></a>
## ☁️ Развёртывание

Для запуска через Gunicorn на Linux, после установки зависимостей и инициализации БД:

```bash
gunicorn -w 4 -b 0.0.0.0:8000 app:app
```

На хостинге укажите нужный порт в команде Gunicorn, настройте переменные окружения и HTTPS через обратный прокси или средства платформы.

### Amvera и платформы с постоянным хранилищем

1. Подключите постоянное хранилище к `/data`.
2. Создайте таблицы в `/data/database.db`.
3. Задайте `SECRET_KEY` и, если нужен ИИ-чат, `GEMINI_API_KEY`.
4. Настройте запуск `app:app` через Gunicorn и порт веб-процесса.

Перед публичным запуском устраните ограничения, перечисленные ниже.

<a id="limitations"></a>
## 🚧 Ограничения текущей версии

Проект создан для хакатона. В текущей реализации есть особенности, которые следует учитывать при дальнейшем развитии:

- **Пароли хранятся в открытом виде.** Перед использованием с реальными аккаунтами необходимо добавить хеширование паролей.
- **Ключ Finnhub находится на клиенте.** Перенесите обращения к сервису на сервер, если токен должен оставаться секретным. Опубликованные секретные ключи нужно заменить.
- **Игровая логика и сохранение состояния зависят от клиента.** Перед соревновательным публичным запуском стоит проверить серверную валидацию балансов и операций.
- **Рейтинг учитывает только `usd + deposit`.** Стоимость активов и балансы KZT/JPY в эту формулу не входят.
- **Курсы валют фиксированы, часть активов симулируется.** Результаты отражают правила игры, а не полноценную модель реального рынка.
- **В `app.py` есть повторяющиеся фрагменты.** При развитии проекта стоит убрать дублирование и добавить форматирование и статическую проверку кода.
- **Публичному API нужны ограничения частоты запросов.** При размещении фронтенда на отдельном домене также потребуется настроить CORS.
